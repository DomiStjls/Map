# Map

Учебное приложение Яндекс.Лицея для просмотра карты и поиска мест. Интерфейс написан на PyQt5; запросы к картографическим сервисам вынесены в `q.py`.

## Запуск

```bash
git clone https://github.com/DomiStjls/Map.git
cd Map
pip install PyQt5 requests Pillow
python map.py
```

Приложению нужен интернет и доступ к используемым картографическим API. В коде указаны старые адреса сервисов и ключи; их актуальность и работоспособность не проверены.

## Структура

- `map.py` и `map.ui` — интерфейс.
- `q.py` — запросы карты и поиск.
- `ans.jpg` — изображение в репозитории; при работе приложение создаёт `ans.png`.
